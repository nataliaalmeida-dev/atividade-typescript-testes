# atividade-typescript-testes
Atividade prática de TypeScript, Promise, async/await e testes unitários.
Implementar exemplos práticos utilizando TypeScript, trabalhando com arrays, objetos, funções assíncronas, Promise, async/await e testes unitários.

## Conteúdos utilizados

- Arrays
- Objetos
- Funções
- Promise
- async/await
- Fluxo assíncrono
- Testes unitários
- Jest
